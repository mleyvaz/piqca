# Ettensperger and Schleutker (2025) replication data

Not redistributed here. Download `Data_QCA_full.csv` and `Data_QCA2_nxx.csv` from the authors' replication archive
(Harvard Dataverse) for Ettensperger, F., & Schleutker, E. (2025), Zeitschrift fuer Vergleichende Politikwissenschaft,
https://doi.org/10.1007/s12286-025-00639-w, and place them in this folder. Then run `R/c01_preparar.R`.
